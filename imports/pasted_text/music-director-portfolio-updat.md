Update the existing music director portfolio website by incorporating the new client requirements below. Do NOT redesign the website from scratch. Treat the current website as the established visual and interaction system and extend it naturally.

IMPORTANT — Preserve the existing design
Keep the existing visual identity, color palette, typography, spacing, layouts, animations, transitions, navigation style, card treatments, imagery style, and overall premium cinematic feel.
Do not replace or unnecessarily restructure the existing pages.
Do not introduce a completely different UI style.
Reuse existing components, buttons, cards, typography, hover states, modal styles, carousels and interaction patterns wherever possible.
New functionality should feel as though it was always part of the website.
Maintain the existing global music player behavior. Music started from Discography or any other part of the site must continue playing while navigating between sections, with play/pause/stop and track information available globally.
Ensure the website remains responsive and maintains the same experience on desktop and mobile.
1. Expand the site's content/navigation structure

The client wants the music director's work organized into the following categories:

Films
Singles
Background Scores
Albums
Advertisements
Devotional
Independent Music

Keep the existing primary navigation style, but update the information architecture so these categories can be accessed naturally.

Important: Do not simply add a large number of new top-level navigation items if that disrupts the current navigation. Use the existing navigation/menu pattern and introduce these categories in the most elegant way possible.

The existing Films and Discography sections should be evolved rather than duplicated.

2. Films — enrich each film/project

Keep the existing Films page with Released and Upcoming carousels.

When a user selects a film, introduce a richer Film Detail / Project Detail view using the existing visual language.

Each film can contain:

Film artwork/poster
Film title
Release status
Story behind the composition
Director
Producer
Lyricist
Singers
Recording studio
Instruments used
Trailer or embedded video
Credits

Structure this information in a visually elegant hierarchy rather than displaying it as a plain list.

For example:

Hero area with film artwork/title
Short story/introduction about the composition
Credits / collaborators
Recording and instrumentation information
Embedded trailer/video
Music associated with the film

If the film has associated songs, allow those songs to use the existing global music player.

Make sure the film detail page feels immersive and cinematic while still matching the existing website.

3. Expand Discography / Music categorization

The client wants music organized into additional categories:

Background Score
Melody Songs
Action Themes
Folk Music
Classical Fusion
Electronic Music
Orchestral Composition

Integrate these categories into the existing Discography experience rather than creating a disconnected new page.

Users should be able to browse/filter music by category.

Continue using the existing song-list UI and global audio player.

Each track should support:

Play
Pause
Track progress
Track title
Album/project information
Category

The player must remain persistent while navigating through the website.

4. Singles

Add a dedicated way to browse Singles.

Use the same music-list/card system already established in Discography.

Each single should support:

Artwork
Song title
Release information
Play button
Optional description/details

All songs must use the existing global music player.

5. Albums

Expand the existing Discography concept to support Albums.

An album should have:

Album artwork
Album name
Year/release information
Track list
Individual play buttons
Play-all capability where appropriate

Clicking an album should open an album detail view while maintaining the current visual style.

6. Advertisements

Add an Advertisements category for commercial compositions.

Present these as a visually rich collection of projects.

Each advertisement/project can contain:

Campaign/project title
Brand/client
Music/composition details
Embedded advertisement video where available
Credits
Playable music where applicable

Reuse the existing Films/project-card visual language rather than introducing a new card style.

7. Devotional

Add a Devotional music category.

Use the existing Discography/song browsing experience.

Support:

Artwork
Song title
Album/project
Description where available
Play button

Keep the experience consistent with all other music categories.

8. Independent Music

Add an Independent Music category for compositions that are not associated with films, advertisements or other commercial projects.

Use the existing music-card/list system and global player.

9. Moments — expand the existing gallery

Keep the existing Moments section and its current image gallery interaction.

Expand it to support different types of behind-the-scenes content:

Studio photos
Recording sessions
Orchestra recordings
Live musicians
DAW/software screen captures
Behind-the-scenes videos

Maintain the existing gallery behavior:

Clicking an image opens the gallery/lightbox.
Users can move between items using left/right navigation.
Support both images and videos in the same gallery experience.
Preserve the existing cinematic presentation and transitions.

Consider adding subtle category filtering if it fits naturally into the existing design, but do not overcrowd the Moments page.

10. Story / Composition stories

Enhance the existing The Story section where appropriate to accommodate the client's request for:

"Story behind the composition."

This should also be available at the individual film/project level where a specific composition has its own story.

Use editorial storytelling rather than presenting it as a generic text block.

The goal is to make the portfolio feel personal and authentic, giving visitors insight into how and why the music was created.

11. Contact / Connect section

Add a clear but elegant way for visitors to contact/connect with the music director.

Include:

Contact
WhatsApp
Email
Instagram

Use the existing button and interaction styles.

These should be functional links:

WhatsApp → open WhatsApp conversation
Email → open email client
Instagram → open Instagram profile

Do not make these visually dominant enough to compete with the portfolio content.

12. Google Location

Add a Google Location / Location option within the Contact area.

It should open the music director/studio location in Google Maps.

Present it elegantly as part of the contact information rather than creating a separate unnecessary page.

13. Overall information architecture

Organize the experience so that visitors can easily understand:

Who he is → His story → His films → His music → His other compositions → His creative process → His moments → Contact

The portfolio should feel like an immersive archive of a music director's career, rather than a conventional corporate portfolio website.

14. Interaction and visual principles

Continue the existing cinematic/music-focused experience:

Smooth transitions
Subtle hover interactions
Strong use of imagery
Editorial typography
Generous spacing
Immersive project pages
Minimal but expressive UI
Consistent controls
Consistent card and carousel behavior

Avoid:

Generic dashboard UI
Excessive cards
Too many visible filters
Large amounts of unnecessary text
Completely new colors
Generic icon sets that don't match the existing design
Redesigning existing sections just for the sake of adding the new requirements

Most importantly: extend the current website, don't replace it. Reuse the existing components and visual language wherever possible.
